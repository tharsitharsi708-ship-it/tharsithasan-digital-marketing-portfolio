# Tharsi Thasan – Portfolio
Next.js 14 (App Router) + Tailwind CSS 3.

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

All copy is in `data/content.js`. Colors (light and dark) are CSS variables at the top of `app/globals.css`.
Deploy to Vercel and point tharsi.xyz at it.
